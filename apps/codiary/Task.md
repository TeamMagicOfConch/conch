# Co-Diary 토스트 메시지 정리

## 일반 사용자

| 상황                    | 타입    | 메시지                                           | 위치            |
| ----------------------- | ------- | ------------------------------------------------ | --------------- |
| 로그인 성공             | success | `환영합니다, {이름}님!`                          | App.tsx         |
| 로그인 실패             | error   | `로그인 실패`                                    | App.tsx         |
| 로그아웃                | success | `로그아웃되었습니다`                             | App.tsx         |
| 세션 참여 실패          | error   | `세션 참여 실패`                                 | App.tsx         |
| 일기 제출 완료          | default | `소라고동에게 내 일기에 대한 답변을 요청했어요.` | DiaryEditor.tsx |
| 일기 저장 실패          | error   | `일기 저장 실패`                                 | App.tsx         |
| 답변 저장 완료          | success | `답변이 저장되었습니다`                          | App.tsx         |
| 답변 저장 실패          | error   | `답변 저장 실패`                                 | App.tsx         |
| 리뷰 저장 완료          | success | `리뷰가 저장되었습니다`                          | App.tsx         |
| 리뷰 저장 실패          | error   | `리뷰 저장 실패`                                 | App.tsx         |
| 시간 연장 요청 실패     | error   | `시간 요청 실패`                                 | App.tsx         |
| 일기 히스토리 로드 실패 | error   | `일기를 불러올 수 없습니다`                      | App.tsx         |
| 답변 로드 실패          | error   | `답변을 불러올 수 없습니다`                      | App.tsx         |
